      What you are looking at

      A deterministic synthetic Nasdaq TotalView-ITCH 5.0 feed is generated and then replayed message by message through the same C++ code as the native build: zero-copy parser, price-time priority L3 books in an index-addressed pool, and a custom open-addressing order-id map. The page only reads results out of WebAssembly memory. It never reimplements book logic in JavaScript.

      Engine latency is the wall time spent inside the engine per message (render excluded). Benchmark replays the whole feed with no rendering. Natively on Linux the engine sustains about 6M msg/s with p50 around 100 ns. See the benchmarks.
